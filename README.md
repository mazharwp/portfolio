# Mazhar Ali – Portfolio (Next.js)

Portfolio site built with [Next.js](https://nextjs.org) (App Router).

## Scripts

- `npm run dev` – start the dev server at http://localhost:3000
- `npm run build` – create a production build
- `npm start` – serve the production build

## Structure

- `src/app/` – routes (`/`, `/about`, `/resume`, `/services`, `/portfolio`, `/contact`) and the root layout
- `src/views/` – page content components
- `src/components/` – Header, Footer, Styleswitcher
- `src/assets/` – CSS and images
- `public/` – static files (favicon, resume download)
